# Software Development Projects

A collection of web and software projects I have built, mainly in Python, Django, and JavaScript.

## Projects

| Project | What it does | Stack |
|---|---|---|
| [Crop Prediction (Django)](Crop-Prediction-Django/Crop-Prediction-Django) | Takes soil and environmental inputs and recommends a suitable crop | Python, Django |
| [Face authentication](Face%20authentication) | API that takes two face images and says whether they are the same person, with a similarity score and face bounding boxes | Python, FastAPI, DeepFace (FaceNet), OpenCV |
| [Web scraping](web%20scraping) | Scrapes laptop listings from Amazon.in (title, price, rating, link) into a timestamped CSV | Python, requests, BeautifulSoup, pandas |
| [Task Manager](Task%20Manager) | Task manager web app with a Node.js backend (routes, models, and a database connection) | Node.js, [Express / MongoDB: confirm], JavaScript |
| [Student management system](student%20management%20system) | Web app to store and manage student records, with a Python backend and a database | Python, [Flask: confirm], SQLite, HTML, CSS, JavaScript |

## How to run a project
Each project has its own folder. Open the folder, install what it needs, and run it:

```
pip install -r requirements.txt
python app.py
```

(For the Django project, use `python manage.py runserver` instead.)
